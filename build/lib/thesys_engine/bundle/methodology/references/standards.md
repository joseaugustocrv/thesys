# Standards and Reference Frameworks

Thesys is informed by established systems and software engineering standards and security frameworks. References do not constitute a claim of conformance or certification.

- **ISO/IEC/IEEE 12207:2026** — software life cycle processes across conception, development, operation, maintenance and disposal; explicitly supports concurrent, iterative, recursive and incremental application.
- **ISO/IEC/IEEE 15288:2023** — system life cycle processes applicable recursively to system elements and iteratively across the life cycle.
- **ISO/IEC/IEEE 29148:2018** — requirements engineering processes and information items; ISO currently lists the 2018 edition as current while DIS 29148 is under development.
- **ISO/IEC/IEEE 42010:2022** — architecture description, viewpoints, model kinds and architecture-description structure.
- **ISO/IEC 25010:2023** — product quality model used to structure quality requirements, measures and evaluation.
- **NIST SP 800-218 SSDF 1.1** — secure software development practices integrated into SDLC implementations.
- **OWASP ASVS 5.0.0** — application-security verification requirements for technical security controls.

The methodology deliberately does not prescribe one development methodology or architecture style. It provides executable controls that can be mapped to the needs and risk profile of a project.
